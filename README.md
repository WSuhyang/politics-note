# 🐴 정치백과

정치 입문자를 위한 학습 사이트 — 인물 관계도 · 인물백과 · 정책백과 · 공약 이행도 · 용어사전.

## 🌐 사이트 바로가기

### **→ [https://wsuhyang.github.io/politics-note/](https://wsuhyang.github.io/politics-note/)**

## 수록 내용

| 탭 | 내용 |
|---|---|
| 정치 관계도 | 77명 인물 · 75건 관계를 가로 타임라인(1948~현재) 위에 시각화. 진영·직급·관계 유형 필터, 정당지도 통합 |
| 인물백과 | 77인 프로필 (출신·학력·경력, 위키백과 연결) |
| 정책백과 | 건국~현재 주요 정책 38건 (배경·내용·결과·출처, 정부별 필터) |
| 공약 이행도 | 대선·총선·지방선거 공약과 뉴스 기반 이행 현황 |
| 용어 사전 | 정치 필수 용어 43개 + 최신 뉴스 링크 |

## 구조

```
v4.html            메인 페이지 (index.html은 이 파일의 복사본)
data/*.json        원천 데이터 (인물·관계·정책·공약·용어·정당·대통령)
scripts/build.js   데이터 검증 + data.js 번들
scripts/fetch_*    위키백과·Commons·뉴스 수집 스크립트
```

데이터 수정 → `node scripts/build.js` → 커밋 & 푸시하면 자동 배포됩니다.
